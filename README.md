# 자율군단 지휘학교

A fixed-desktop browser game about designing command conditions for autonomous officers.

[Play the deployed game](https://gold0827.github.io/codex-game/)

[Submission sheet](docs/submission/submission.ko.md) · [Thumbnail](docs/submission/thumbnail.png)

## How to play

- Set information reach, authority clarity, verification depth, and feedback compression within the briefing budget.
- Start the operation, then observe the battlefield, officer intent, hazards, and incoming reports.
- Pause or run at 0.5×, 1×, or 2× speed.
- Spend limited direct interventions to route reports, authorize officers, or prioritize verification.

The campaign contains six operations, beginning with the guided communications school and ending with a final combined crisis. Successful operations unlock the next briefing; failed operations can be retried. Completing all six reaches graduation.

`작전 교범` opens the in-game field manual from any phase. `장면 편집` opens the separate all-scene editor; restart the campaign from the editor to play edited content.
